# Customer Order Tracking Dashboard

A Python and Streamlit-based dashboard designed to simplify customer order tracking and support production planning decisions.

## Overview
This dashboard integrates data from multiple sources, including monthly delivery plans, production schedules, warehouse inventory, ongoing production orders, and shipment records, providing a unified view of customer order status.

## Key Features
- **Order Tracking:** Monitor the fulfillment status of each product.
- **Production Monitoring:** Track ongoing production and identify orders without production plans.
- **Inventory & Shipment Tracking:** Monitor available stock, shipped quantities, and remaining requirements.
- **Delivery Monitoring:** Identify supply shortages and potential delivery delays.
- **Time-Based Analysis:** Review upcoming delivery commitments and identify orders at risk.

## Technologies
- Python
- Streamlit
- Pandas

## Purpose
To improve production planning visibility, reduce manual tracking efforts, prevent overlooked orders, and support on-time customer deliveries.
